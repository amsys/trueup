# Contributing

Thank you for your interest in this project.

## Before you start

- Read the README for the project's purpose and setup steps.
- Open an issue before a large change, so the design can be agreed first.

## Making a change

1. Create a branch for your change.
2. Make the change, with tests where the project has a test suite.
3. Run the project's lint and test commands before you open a pull request.
4. Open a pull request that describes what changed and why.

## Code style

Follow the style already used in the file you are changing.

## Reporting a bug

Open an issue with the steps to reproduce it, what you expected, and what
happened instead.
