# Code of conduct

## Our standard

Everyone who takes part in this project treats other people with respect.
Disagree with ideas, not with people.

## Unacceptable behavior

- Insults, personal attacks, or harassment of any kind.
- Sharing the private information of another person without their consent.
- Any conduct that would be unreasonable in a professional setting.

## Reporting a problem

Send a report to <dev@amsys.cz>. The maintainer reads and answers each
report, and keeps the name of the reporter private.

## Enforcement

The maintainer can remove a comment, a commit or an issue that breaks
this code, and can block a person who breaks it again. A maintainer who
breaks this code gets the same consequences as any other person.
